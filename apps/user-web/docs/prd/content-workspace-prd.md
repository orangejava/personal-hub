# 内容工作区 PRD：上传、导入与编辑

> 状态：规划中
> 最后更新：2026-06-09
> 优先级：P1
> 适用范围：`/workspace/content`、`/workspace/booklets`、`/workspace/markdown`

---

## 1. 模块目标

内容工作区负责把文档从“本地素材”变成“平台内可管理、可阅读、可发布的内容资源”。

首版目标：

- 管理当前用户有权限操作的内容列表。
- 支持 Markdown 文档创建、编辑、预览、保存草稿、发布。
- 支持掘金小册 ZIP 导入、导入结果查看、打开阅读、下载源文件。
- 支持内容基础信息维护：标题、摘要、封面、分类、标签、可见性。
- 支持草稿、发布、归档、删除等基础生命周期。

暂不做：

- Word 在线编辑。
- 富文本多人协作。
- 小册增量导入。
- 图片自动转存和资源重写。
- 内容审核流。

| 普通会员 | ❌ | ❌ | ✅ | ❌ | ❌ |
| 编辑者 | ✅ 本人 | ✅ | ✅ | ✅ | ✅ 本人 |

## 4. 内容列表页

### 4.1 页面结构

```txt
┌────────────────────────────────────────────────────┐
│ 标题：文档管理                         [新建内容]   │
├────────────────────────────────────────────────────┤
│ 筛选：类型 / 状态 / 可见性 / 分类 / 关键字           │
├────────────────────────────────────────────────────┤
│ 表格：封面 标题 类型 状态 可见性 更新时间 操作        │
└────────────────────────────────────────────────────┘
```

### 4.2 筛选字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | enum | all | 小册 / PDF / Word / Markdown / 富文本 / 外链 |
| `status` | enum | all | draft / published / archived |
| `visibility` | enum | all | public / login / private |
| `categoryId` | string | 空 | 分类筛选 |
| `keyword` | string | 空 | 标题、摘要搜索 |
| `page` | number | 1 | 页码 |
| `pageSize` | number | 20 | 每页数量 |

### 4.3 表格字段

| 字段 | 说明 |
|---|---|
| `cover` | 封面缩略图，无封面显示类型占位 |
| `title` | 标题，点击进入阅读页 |
| `type` | 内容类型标签 |
| `status` | 草稿 / 已发布 / 已归档 |
| `visibility` | 公开 / 登录可见 / 私有 |
| `category` | 分类名称 |
| `updatedAt` | 最后更新时间 |
| `actions` | 编辑、预览、发布/下线、归档、删除 |

### 4.4 操作逻辑

| 操作 | 规则 |
|---|---|
| 新建内容 | 进入 `/workspace/content/new` |
| 编辑 | 根据类型跳转编辑页，Markdown 进入 `/workspace/markdown/:id` |
| 预览 | 打开公开阅读页，草稿内容仅作者和管理员可预览 |
| 发布 | `draft` → `published`，写入 `publishedAt` |
| 下线 | `published` → `archived` |
| 归档 | 任意非 archived 状态 → `archived` |
| 删除 | 二次确认，仅作者或管理员 |

## 5. 内容创建向导

### Step 1：选择内容类型

| 类型 | 首版支持 | 下一步 |
|---|---:|---|
| Markdown | ✅ | 进入 Markdown 编辑器 |
| 掘金小册 | ✅ | 进入小册导入 |
| PDF | ✅ 基础上传 | 上传文件并入库 |
| Word | 预留 | 后续进入 Word 编辑器 |
| 富文本 | 预留 | 后续进入富文本编辑器 |
| 外部链接 | ✅ 简单录入 | 填写 URL 和基础信息 |

### Step 2：基础信息

| 字段 | 必填 | 校验 | 默认值 |
|---|---:|---|---|
| `title` | ✅ | 1-100 字 | 空 |
| `summary` | ❌ | 最多 500 字 | 自动截取正文前 200 字 |
| `cover` | ❌ | URL 或文件资源 | 空 |
| `categoryId` | ✅ | 必须存在 | 空 |
| `tagIds` | ❌ | 最多 10 个 | 空数组 |
| `visibility` | ✅ | public / login / private | login |

### Step 3：输入内容

| 类型 | 输入方式 |
|---|---|
| Markdown | 文本编辑器输入 `contentRaw` |
| 掘金小册 | 上传 ZIP 包，解析 `meta.json` 和章节 Markdown |
| PDF | 上传 PDF 文件 |
| 外部链接 | 输入 URL |

### Step 4：保存

按钮：

- `保存草稿`
- `发布`
- `取消`

规则：

- 保存草稿只要求标题、分类、内容类型合法。
- 发布要求正文或文件存在。
- 发布失败保留当前表单数据。

## 6. Markdown 编辑器

### 6.1 页面结构

```txt
┌────────────────────────────────────────────────────┐
│ 顶部栏：标题输入 状态 [保存草稿] [发布] [预览]       │
├──────────────────────────┬─────────────────────────┤
│ Markdown 编辑区           │ 预览区                   │
└──────────────────────────┴─────────────────────────┘
```

移动端：

- 编辑和预览使用 Tabs 切换。
- 顶部操作收进更多菜单，保留保存主按钮。

### 6.2 编辑字段

| 字段 | 说明 |
|---|---|
| `title` | 顶部可直接编辑 |
| `contentRaw` | Markdown 原文 |
| `summary` | 可手动填写，不填自动生成 |
| `categoryId` | 基础信息抽屉中编辑 |
| `tagIds` | 基础信息抽屉中编辑 |
| `visibility` | 基础信息抽屉中编辑 |

### 6.3 功能逻辑

- `Ctrl/Cmd + S` 保存草稿。
- 保存前本地校验标题、分类、正文长度。
- 预览使用前端临时渲染，最终发布以后端渲染结果为准。
- 保存成功后 Toast 提示，并更新 URL 到 `/workspace/markdown/:id`。
- 离开页面且有未保存改动时弹出确认。

## 7. 小册导入与管理

### 7.1 导入 ZIP 格式

```txt
booklet.zip
├── meta.json
├── chapter-01-intro.md
├── chapter-02-setup.md
└── ...
```

`meta.json` 字段：

| 字段 | 必填 | 说明 |
|---|---:|---|
| `title` | ✅ | 小册标题 |
| `author` | ❌ | 原作者 |
| `summary` | ❌ | 简介 |
| `cover` | ❌ | 封面文件名或 URL |
| `categorySlug` | ❌ | 分类 slug |

### 7.2 导入流程

1. 上传 ZIP。
2. 后端检查文件大小、扩展名、解压安全。
3. 解析 `meta.json`。
4. 按章节文件名前缀排序。
5. 渲染每章 Markdown，生成 `content_chapters`。
6. 创建 `contents` 主记录，状态默认 `draft`。
7. 展示导入结果。

### 7.3 导入结果页

| 字段 | 说明 |
|---|---|
| `title` | 小册标题 |
| `totalChapters` | 解析到的章节数 |
| `successCount` | 成功导入章节数 |
| `failedItems` | 失败文件、失败原因 |
| `contentId` | 生成的小册 ID |

操作：

- `打开阅读`
- `继续编辑信息`
- `重新导入`
- `返回小册管理`

### 7.4 小册管理页

页面区域：

- 左侧小册列表。
- 右侧小册详情。
- 顶部上传、搜索、批量下载。

操作：

- 打开阅读。
- 下载源文件。
- 编辑基础信息。
- 删除小册。

## 9. 状态与异常

| 场景 | 行为 |
|---|---|
| 列表为空 | 展示空状态和新建按钮 |
| 保存失败 | Toast 展示错误，保留输入 |
| 未保存离开 | 弹确认 |
| ZIP 缺少 `meta.json` | 阻止导入并提示 |
| 章节文件为空 | 标记失败项 |
| 无权限编辑 | 403 |
| 删除有关联文件 | 删除内容，不直接删除仍被引用的文件 |

---

## 10. 验收标准

- 能创建 Markdown 草稿。
- 能保存并再次打开 Markdown 草稿。
- 能发布 Markdown 并在内容中心阅读。
- 能上传符合格式的小册 ZIP。
- 能看到导入成功/失败明细。
- 能从小册管理页打开小册阅读。
- 删除、归档、发布等危险操作都有确认或明确提示。
