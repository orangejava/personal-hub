# 公开入口备案信息

> 状态：已实现
> 最后更新：2026-10-15

ICP备案号统一维护在 `src/config/siteFiling.ts`。`SiteFiling` 组件负责展示及工信部查询链接，仅在主站首页 `/` 和 AI 工具首页 `/ai` 的内容末尾挂载。AI 对话等工具操作页、登录页、工作区和后台不挂载，避免占用固定操作区域。

备案区域参与页面自然滚动，不采用固定定位；长文字可换行，链接保留手机触控高度与底部安全区。用户提供的 32 位公安联网备案数据码并非可直接展示的“公网安备……号”，取得正式公安备案号后再补展示和对应查询链接。

已在 Chromium 排版引擎中使用组件实际样式测量 375、767、768、991、992、1440px 六个宽度：备案区没有造成横向溢出，链接保持 44px 高度，页脚与前一区块自然衔接。完整页面验收未完成：当前本地依赖缺少 `web-vitals`，Umi 首页停留在资源加载画面；补齐依赖后需在上述宽度分别打开 `/` 与 `/ai`，滚动至底部检查视觉与控制台，再打开 `/ai/chat` 确认输入区没有受到影响。
