# personal-hub

个人知识中台 + 内容管理平台 + AI 工具箱。

## 当前阶段

React-first：`apps/react-web`（Umi + Ant Design Pro + mock）。

## 本地启动

```bash
pnpm install
pnpm sync:booklets   # 需本地 content-local/（不进 Git）
pnpm dev:react
```
