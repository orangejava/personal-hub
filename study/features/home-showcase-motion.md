# 首页滚动区块怎么拆

## 场景

长首页要按滚动逐块出现，又不能整页吸附、不能把动效库打进入口包。

## 做法

1. 页面只依赖自己的四个组件：进入视口、错落、固定一段用滚动进度驱动、提前量检测。
2. 动效库放在路由分包里，动画功能包再异步加载。系统开启减少动态效果时关掉位移，只留淡入。
3. 首屏以外的区块先占高度，进入视口附近再挂载。数据请求写在子组件里，这样不挂载就不会发请求。
4. 桌面滚动场景不要用在手机、平板和矮屏。这些档改成普通纵向排列。

## 常见坑

- 后台模块列表是数组。对象浅合并会用旧数组盖掉新 key，缺的区块要在读配置时按 key 合并。
- `html, body, #root { height: 100% }` 再加手机档 `overflow-x: hidden` 时，长页面不会撑开文档，手机上滑不下去。页面自己的 less 离开路由后仍留在文档里，不要无条件改这三个节点。用 `useDocumentGrows` 在当前页挂载时加上 `ph-document-grows`，样式只命中这个类，离开页面再拿掉。
