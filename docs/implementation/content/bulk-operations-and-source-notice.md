# 来源说明与管理列表批量操作

## 1. 目标与范围

单条导入内容发布时允许填写来源说明，弹窗预填“网络下载，侵权联系”，并保存到内容主表以供后台查找；批量发布保留每条内容原有来源说明，不自动补默认值。公开接口不返回来源说明。工作区内容、后台内容、小册、审核、分类和标签列表支持多选操作，执行期间禁用重复提交；文件列表原本已有批量删除。

## 2. 数据与调用链

发布弹窗 `sourceNotice` → `POST /app/contents/:contentId/publish` 或 `POST /admin/contents/:contentId/publish` → `ContentService` 更新 `Content.sourceNotice` → 管理端/工作区列表返回 → 后台文档列表关键字可匹配标题、摘要和来源说明；公开列表、详情、收藏列表不包含该字段。

`sourceNotice` 是选填的来源/联系提示；`copyrightNote` 是解除导入版权闸的授权依据。两者独立持久化，来源提示不会被当作授权证明。版权说明在审核通过时写入 `content_reviews.copyright_note`，清闸时也进入审计记录；管理员直接发布会写入清闸审计记录。公开阅读页不展示版权说明。

## 3. 批量操作

多选操作在页面端逐项调用现有单条接口，每次最多并发 5 项。这样每条记录仍执行原权限、幂等和业务校验，也不会一次选中 100 行就同时发出 100 个写请求。结果以成功/失败数量反馈，并列出部分失败 ID。审核批量通过若包含仍受版权限制、目标公开或登录可见的项目，要求填写一份适用于这些项目的授权依据，仅向对应审核请求传入；分类和标签在存在子类或内容引用时不能被选中删除。

文档批量发布先选择“保持各自当前可见性”或统一改为公开、登录可见、私密。管理员直接发布的选中项若包含仍受版权限制、且目标对外可见的导入内容，表单要求填写一份适用于这些选中项的真实授权依据，并仅向这些项的发布请求传入 `copyrightNote`。工作区编辑者提交审核时不填写，由管理员审核通过时补充（可逐条或批量）。该批量弹窗不编辑来源说明，已有值原样保留。

管理端和工作区共用 `packages/shared-types/src/content-batch-policy.ts` 判断逐项是否需要版权说明，并生成批量发布参数。工作区仍先判断是否具有 `content:publish` 的 ALL 权限：编辑者提交审核不传版权说明。审核队列的通过规则只用于管理端审核页，保留在该应用内。

后台文档支持批量发布、归档、精选和删除；工作区文档支持发布/提交审核、归档和删除；内容审核支持批量通过/统一原因驳回；小册、未使用标签和无引用分类支持批量删除。

## 4. 验证

1. 在工作区打开导入内容发布弹窗，确认来源说明默认填充，可编辑并提交。
2. 后台文档列表用完整或部分来源说明搜索，确认目标内容出现。
3. 在各列表选中多条记录，分别运行操作；检查成功提示、失败 ID，以及有引用的分类/标签被禁选。

页面端批量功能需桌面/移动浏览器验收。管理端工具栏使用可换行操作区；工作区沿用现有表格的响应式行为。
