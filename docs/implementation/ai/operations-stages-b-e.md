# AI 后台阶段 B-E 实现记录

## 范围

阶段 B 支持用户自备 OpenAI-compatible 厂商、Key、文本模型和自备模式；阶段 C 支持用量统计、平台实扣与价格估算分离、超级管理员额度调整；阶段 D 支持上海自然日每日首次成功登录奖励；阶段 E 支持签到日历、连续天数和第 7 天循环奖励。

## 本轮体验扩展

- 登录和成功 refresh 都调用每日活跃奖励服务，使用 `daily-login:<userId>:<上海日期>` 统一幂等；认证失败和奖励异常不影响认证结果。
- 用户端新增 `/workspace/ai` AI 管理首页，聚合真实额度、签到状态、最近使用模型和快捷入口；自备厂商迁移到 `/workspace/ai/providers`，旧 AI 历史地址继续保留。
- 签到使用单月日历、年月选择器、左右切月和回到本月，不采用无限滚动。
- 管理端额度调整支持按邮箱或昵称搜索用户，内部仍以 User UUID 作为账本关联主键。
- AI 统计在原有 Token、调用、实扣、估算基础上，聚合生成任务成功率、失败数、平均耗时、状态分布和真实任务来源；聊天与生成调用均写入 `ai_usage_records.latency_ms`，历史生成任务仍使用任务起止时间。
- 统计页的 Token 和调用次数分别绘图，各用自己的数值刻度；生成任务状态显示中文名称和语义颜色。额度调整表单只在原请求参数不变时复用幂等键，改动用户、方向、金额或原因后生成新键。
- 管理端统计按主键分页读取用量与任务（每批 500 条），在内存中只保留日期、工具、用户、模型维度的聚合；图表配色跟随后台主题。
- 会员页近 30 天用量按上海自然日查询，趋势和工具分布由数据库对全部匹配记录聚合；使用明细独立分页，超过一页也不会少算。

## 调用链

- B：个人中心调用 `/app/ai/credentials`、`/app/ai/user-models` 和 `/app/ai/provider-preferences`。浏览器用服务端公钥加密 Key，服务端只保存密文；Chat/Text 解析系统模型或用户模型后再进入 SSE Provider。
- C：`/admin/ai/stats?range=24h|7d|30d` 直接聚合 `ai_usage_records`；`/admin/ai/quota-adjustments` 通过条件更新账户并写 `ADJUSTMENT` 账本。
- 预占结算返回明确结果；任务成功、用量和结算同事务，已释放的预占不能产生成功实扣。聊天终态和过期清理先锁同一预占行，再读写消息状态，避免交错释放；排队或执行中的任务保留预占。图片/视频按创建任务时的预占金额作为价格快照结算。
- 聊天结算条件更新若输给补偿事务，会再次读取预占终态；同金额已结算视为幂等成功，避免账本实扣后用量误记为零。
- D：登录成功和 refresh 成功调用 `AiRewardService.grantDailyLogin`，失败认证不触发；两条链路共用 `daily-login:<userId>:<上海日期>`。
- E：工作台调用 `/app/ai/checkin` GET/POST；签到记录、余额更新和 `checkin:<userId>:<日期>` 账本在同一事务，规则快照写入记录。

## 安全和验证

用户 Key 不进入响应、Pino 请求体日志或上游错误日志。自建地址只接受 HTTPS 域名，DNS 解析后的 IPv4 必须为公网地址，连接不跟随跳转。自备模式没有匹配 Key、Key 停用或调用失败时直接返回业务错误，不切换系统 Key。自建模型不扣平台额度，估算字段为 `null`，管理端按未知单独计数。

保存自备厂商地址与实际出站请求共用域名校验：拒绝 IPv4 和带方括号的 IPv6 字面量，防止 Node 跳过 DNS 回调直接连接内网地址。DNS 返回的 IPv4-mapped、NAT64、6to4 和 Teredo 地址会解出内嵌 IPv4，再按公网规则校验。后台“允许改选系统模型”关闭时，用户模型目录按工具默认关系过滤；系统模型解析同时约束 Chat/Text 与图片/视频，用户自建文本模型仍可选择。菜单 seed 与迁移都将 AI 历史挂在 AI 管理下，重复 seed 不会恢复顶层入口。

图片和视频草稿在原模型不可用时选用当前工具默认模型；从历史任务直接“再次生成”也在提交前校验模型，避免绕过草稿修正而发送旧模型 ID。历史任务卡片仍显示原模型快照。

管理员暂停自备能力时保留用户的开启偏好，Chat/Text 调用明确拒绝；模型目录通过 `blockedToolTypes` 标记暂停的文本工具，用户端据此禁用发送、新建对话和重新生成，显示关闭个人自备模式的指引，并隐藏额度不足提示。图片/视频仍可使用；用户主动关闭模式后才按系统配置调用。工作区历史的累计 Token 来自输入与输出 Token 之和，与平台实扣额度分别显示；文本模板保留其可用模型，失效后才选择当前默认模型。

Prisma 全量迁移在隔离数据库 `personal_hub_ai_admin_test` 通过；服务端 Nest build、两端和服务端 TypeScript 检查通过；AI Chat 生命周期、预占到期和统计分页的定向测试通过。隔离 API `3002` 的健康检查、会员登录、签到首次领取/重复提交、后台 24h 统计和额度账户读取通过。

内置 IAB Playwright 后端不可用，浏览器登录后的完整路径和 390/820/1440 视口未完成自动化验收；上线前需在可用浏览器环境补齐两用户隔离、Key 网络明文、SSE 停止和四视口截图记录。
