# 运营概览与手机 AI 发送

## 入口与调用链

- 后台 `/admin` 调用 `GET /api/v1/admin/dashboard/overview`，由 `dashboard:read` ALL 守卫保护。Controller 调用 Service，Service 聚合 Prisma 内容与用户计数，并在 PostgreSQL 侧对每日读者标识去重。Umi 请求层解包后，页面直接接收四个数字。
- AI 对话页的提交先由 `useAiChat` 创建会话，再加入本地用户与助手气泡并启动 SSE。创建失败会向页面抛错，页面显示错误且保留草稿；成功加入气泡后才清空本次草稿。创建期间禁止重复发送。
- 多会话生成按会话 ID 保存独立的消息与 SSE 状态。切换仅更换当前视图，原流继续写入原会话；停止按钮只作用于当前会话。包含建会话等待在内，当前页面最多三条会话同时生成；满额时保留输入并提示。异步创建完成后不会覆盖用户随后选择的会话。
- 三条是当前网页的上限。登录用户实际可同时生成的数量还受服务端角色权益 `AiEntitlement.maxConcurrent` 约束；现有角色设置可能低于三条。跨标签页和跨设备仍由服务端权益统一限制。

## 日期与统计口径

`content_view_days.view_date` 使用上海自然日写入，与运营概览的今日查询一致；日期和读者标识上新增索引。周发布范围从上海时间周一零点到当前时刻，使用内容的首次 `publishedAt`；已删除内容不计。读者基于账号或 IP 派生的 `subjectHash`，不是全站访客，也无法准确代表自然人。改动前的历史日期不自动修复。

## 验证

运行 `pnpm --filter user-web exec vitest run src/components/ai/hooks/useAiChat.test.tsx` 与 `pnpm --filter server exec vitest run test/admin-dashboard.spec.ts`。手动在手机宽度首次发消息、模拟建会话失败并重试；在 A 生成时切到 B，再切回 A 核对原回复；三条并行后确认第四条提示且草稿保留。后台以有 `dashboard:read` ALL 的账号打开运营概览，确认四项返回且失败态可重试。

## 深度链路复核与修复（2026-10-16）

- 历史读取按 `createdAt/id` 游标分页；客户端读完各页再合并。请求开始记录会话版本，期间发送/结束/反馈造成版本变化时丢弃旧响应；按 ID 合并保留未入库的失败问题与提示，不以旧 `generating` 覆盖本地终态。
- 停止只针对目标会话。`STARTED` 前点击停止先记录意图，取得服务端消息 ID 后发 stop；保持连接和并发占位，直到服务端终态。停止接口失败由全局提示，允许再次点击。离开页面或断网关闭 SSE 时，服务端也请求停止；页面内切换会话不关闭连接。
- 生成中的对话暂不允许删除。前端确认按钮和服务端都校验；删除与发送共用带持有者 token 的会话锁，发送拿锁后重新校验会话未删除。删除成功后才移除列表，失败保留原会话。
- 服务端消息创建、变体切换及活跃消息指针放在同一事务。重新生成通过额度/并发检查后才隐藏旧回答，复用原问题并保留回答排序时间；上下文取原问题之前的最近窗口，并保证问题在最后。
- Provider 的正常停止异常仍走 STOPPED 落库和结算，保留已收到的正文。无终态的 SSE 断流显式报错；服务端在发出终态前先释放运行时锁与名额。
- 等待首次建会话时离开页面，返回后不再发起不可见的生成。重新生成完成同样刷新额度摘要，回调失败不会阻塞名额释放。

测试分为 React hook 联动、SSE 传输、真实 AiService 控制流（持久层/厂商替身）三层；后者不等于真实 PostgreSQL/Redis HTTP 集成测试。当前页面并发上限为三条，服务端权益仍可能更低。

### 本轮验收结果与限制

- 定向测试：用户端 6 文件 25 项、服务端 3 文件 17 项通过；涉及失败回刷、跨会话生成、三条并发、停止等待终态、删除拒绝/失败、离页、变体重试、历史分页、上游断流、运营统计及备案组件。相关 ESLint/Biome lint、`git diff --check` 通过。
- 全量类型检查未通过：用户端已有 `motion/react`、`web-vitals` 依赖缺失；服务端已有 metrics JSON 导出与 Prisma 生成类型不匹配。本轮修改文件未出现类型错误。
- 当前 main 独立使用 8016 端口启动失败：缺少 `@utoo/pack/package.json`。因此本轮没有有效的 main 页面截图或 390×844 / 768×1024 / 1440×900 布局通过记录，也未验证手机软键盘遮挡。8000 实际属于 ai-admin worktree，误在其 390×844 页面创建了一条“本地回归测试”会话，已停止该页面测试；其结果不计入 main 验收，未改动该 worktree 代码。
- Docker 环境探测失败，未执行依赖 Testcontainers 的完整 HTTP/PostgreSQL/Redis 集成套件；服务端 17 项为定向单元与服务控制流测试。
