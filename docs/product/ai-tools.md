## 定位

AI 工具平台是本项目的**核心主线**。知识内容中心作为 AI 工具的输入源与素材库，两者联动。

长期 PRD 见 [ai-tools-prd.md](../prd/long-term/ai-tools-prd.md)。React-first 阶段 5 的页面级细化见 [phase-5-ai-platform-prd.md](../prd/react-first/phase-5-ai-platform-prd.md)。

---

## 接入架构

```
前端（Web / Flutter）
    ↓ HTTP 请求（含 stream: true 支持 SSE）
后端 NestJS（AI 代理层，隐藏 API Key）
    ↓ 调用对应厂商 API
AI 厂商（OpenAI / Anthropic / 阿里云百炼 / Gemini 等）
```

**关键约束**：
- 前端不直接调用 AI API，全部走后端代理
- 后端记录：使用统计、对话历史、Token 消耗
- 支持后续 Token 计费体系
- 流式输出（Streaming）走 SSE（Server-Sent Events）

---

## API 接入策略

- 不绑定单一厂商，后台可配置：厂商、模型、Key、默认参数
- 优先选 Token 价格最优的厂商（首版默认：阿里云百炼 Qwen）
- 每种工具可单独配置使用哪个模型

候选厂商：

| 厂商 | 模型示例 | 优势 |
|---|---|---|
| 阿里云百炼 | Qwen-turbo / Qwen-plus | 价格低，中文能力强 |
| OpenAI | GPT-4o / GPT-4o mini | 能力全面，生态最广 |
| Anthropic | Claude 3.5 Sonnet | 长上下文，指令遵循强 |
| Google | Gemini 1.5 Flash | 多模态，价格有竞争力 |

## 工具广场（入口页）`/ai`

`/ai` 不再只是公开前台中的一个普通页面，而是 AI 专属工作台入口。

进入 `/ai/*` 后：

- 隐藏公开前台顶部导航。
- 使用 AI 左侧工作栏展示首页、创作父级入口、资产、个人中心、创建团队、创作中心、会员中心、发布、教程、API。
- 登录入口仍保留在 AI 顶部工具条；已登录用户展示 Token 余额、头像和 hover 用户卡。
- 左侧品牌名可以回到公开首页，不再在侧栏底部单独展示返回首页按钮。
- 工具可在后台配置启用/禁用，禁用时显示“即将上线”或“暂不可用”。
- 左侧栏展开/折叠沿用 Ant Design / Ant Design Pro 同类交互。
- AI 品牌名默认 `Personal Hub AI`，但必须支持后台或系统配置修改。

首版工具分组：

| 分组 | 工具 |
|---|---|
| 首页 | AI 工具首页、最近创作、推荐模板 |
| 创作 | AI 对话、文本生成、图片生成、视频生成 mock、WebUI 占位、ComfyUI 占位、LoRA 训练占位、AI 应用 |
| 资产 | AI 生成资产、历史结果、草稿 |

| 帮助与开放 | 发布、教程、API |

## 核心工具（第一版）

### 1. 对话（Chat） `/ai/chat`

#### 页面布局

```
┌───────────────┬────────────────────────────────────┐
│ 会话列表侧栏  │  当前会话对话区                      │
│ 200px        │                                     │
│ ─────────    │  ┌───────────────────────────────┐  │
│ [+ 新对话]   │  │ 消息气泡列表（滚动区域）        │  │
│              │  │                               │  │
│ 会话1        │  │  用户 ───────────────────────▶ │  │
│ 会话2        │  │  ◀─────────────────── AI 回复 │  │
│ ...          │  │  （流式逐字输出）               │  │
│              │  └───────────────────────────────┘  │
│              │  [附件] [引用内容] 输入框  [发送 ↵]   │
└───────────────┴────────────────────────────────────┘
```

#### 功能细节

| 功能 | 说明 |
|---|---|
| 多会话管理 | 支持新建、切换、重命名、删除会话 |
| 流式输出 | SSE 实时逐字显示，有打字光标动效 |
| 上下文记忆 | 默认保留最近 20 条消息作为上下文 |
| 引用知识内容 | 点击"引用内容"，从知识库选一篇内容注入为上下文 |
| System Prompt | 每个会话可自定义 System Prompt（高级设置面板，默认折叠） |
| 模型选择 | 顶部下拉可选择可用模型（后台配置哪些模型对用户可见） |
| 消息操作 | AI 回复支持：复制、重新生成、点踩（反馈） |
| Markdown 渲染 | AI 回复实时渲染 Markdown（含代码块高亮、表格） |
| 停止生成 | 流式输出中可点击"停止"按钮中断 |

#### 会话命名规则
- 新对话默认标题：取第一条用户消息前 20 字
- 用户可手动重命名

#### 权限
- **未登录**：可试用（不保存历史，限 3 轮对话/天）
- **登录用户**：保存历史，使用用户配额

### 2. 文本生成 `/ai/text`

#### 页面布局

```
┌──────────────────────────────────────────────────────┐
│  场景选择：[写作辅助] [改写润色] [摘要提炼] [扩写]     │
│            [翻译]    [续写]    [自定义 Prompt]        │
├──────────────────────────────────────────────────────┤
│  输入区：粘贴或输入原文（最多 8000 字）                │
│  参数面板（右侧，可折叠）：                            │
│    · 模型选择                                         │
│    · 输出长度（短/中/长）                              │
│    · 语气（正式/轻松/专业）                            │
│    · 目标语言（翻译模式用）                            │
├──────────────────────────────────────────────────────┤
│  [生成]                                               │
├──────────────────────────────────────────────────────┤
│  输出区：生成结果（流式输出，支持复制、重新生成）        │
└──────────────────────────────────────────────────────┘
```

#### 支持场景

| 场景 | 内置 Prompt 模板 |
|---|---|
| 写作辅助 | 提供选题、结构建议 |
| 改写润色 | 保留语义，改善表达 |
| 摘要提炼 | 提取核心要点，3-5 条 |
| 扩写 | 基于输入扩展内容 |
| 翻译 | 中↔英，可选目标语言 |
| 续写 | 基于输入内容继续写 |
| 自定义 Prompt | 用户自定义指令，输入原文 |

#### 权限
- **未登录**：可试用（限每日 3 次，输出 500 字以内）
- **登录用户**：使用用户配额，无单次字数限制

### 3. 图片生成 `/ai/image`

#### 页面布局

```
┌──────────────────────────────────────────────────────┐
│ 左侧主内容流：用户输入卡片 + AI 图片输出卡片           │
│ 用户：Prompt / 参数 / 附件图                          │
│ AI：生成中骨架 → 图片网格 1/2/4                       │
│     hover：引用为附件 / 下载 / 查看详情                │
│     底部：再次编辑 / 重新生成                          │
├──────────────────────────────────────────────────────┤
│ 底部输入区：Prompt、附件、尺寸、风格、数量、模型、Seed  │
└──────────────────────────────────────────────────────┘
```

#### 功能细节

| 功能 | 说明 |
|---|---|
| Prompt 辅助 | 提供常用风格词快速标签（点击追加到 Prompt） |
| 生成历史 | 用户生成的图片保存到"我的用量 - 图片历史"（后续） |
| 保存到库 | 生成结果可一键保存为内容库条目（type=image，后续） |
| 下载 | 直接下载原始尺寸图片 |
| 引用为附件 | 将当前图片作为下一次生成的参考附件 |
| 再次编辑 | 将本次 Prompt、参数和附件图回填到输入区 |
| 重新生成 | 复用本次输入和参数再次请求后端 |

#### 权限
- **未登录**：不可使用，点击后引导登录
- **登录用户**：消耗用户配额（图片生成按次计费，1 次 = X Token 等价）

### 4. 视频生成 `/ai/video`

阶段 5 先做 mock 创作流，不接真实视频生成后端。

交互与图片生成保持一致：

- 用户输入和 AI 输出统一展示在左侧主内容流。
- 输出卡片展示视频封面、状态、时长、比例和模型。
- 视频 hover 时展示：引用为附件、下载、查看详情。
- AI 输出底部展示：再次编辑、重新生成。
- 再次编辑回填 Prompt、参考图/视频、模型、比例和时长等参数。

## Token 计费体系

### 配额模型

| 项目 | 说明 |
|---|---|
| 初始配额 | 新注册用户赠送 10,000 Token |
| 配额类型 | 统一 Token 池，不区分工具类型 |
| 图片折算 | 1 次图片生成 = 消耗 500 Token |
| 计费周期 | 不按月重置，消耗完为止（首版） |
| 查看入口 | 工作区"我的用量"页 |

### 充值体系（后续版本）
- 首版仅预留数据结构，不上线充值功能
- 管理员可在后台手动为用户增加配额（首版替代方案）

### 后台统计看板（见 admin.md）
- 全平台 Token 消耗趋势
- 用户消耗排行
- 各工具消耗占比
- 实际 API 费用估算
