# 素材库

> 状态：已确认要做，未排期，**不是当前开发依据**
> 最后更新：2026-10-09
> 来源：`home-showcase` 首页与项目页改版期间的讨论
> 相关：[file-policies.md](./file-policies.md)、[workspace-pages.md](./workspace-pages.md)（个人文件库仍待讨论）、[content-booklet-file-prd.md](../../prd/long-term/content-booklet-file-prd.md)（文件域契约）

## 要解决的问题

站里显示图片的地方越来越多：首页精选示例、项目页封面、作品预告、正文插图、AI 生成图。现在这些图分在两处，没有一个地方能统一查到：

| 来源 | 现在在哪 | 现在怎么查 |
| --- | --- | --- |
| 随代码提交的占位图（SVG） | `apps/user-web/public/images/` | 只能看清单 `apps/user-web/src/config/publicImageCatalog.json` |
| 后台上传的项目封面、截图 | 对象存储，`file_assets` 里 `purpose = COVER` | 只能到项目配置页逐个端看 |
| 内容封面 | 对象存储，`purpose = COVER` | 只能在内容编辑里看 |
| AI 生成图 | 对象存储，`purpose = AI_ASSET` | 用户在 AI 资产里看自己的 |

本地开发时加的图、上传过的图都要有记录，以后能在素材库里查到，并且能带到生产。

## 目标

1. 管理端有一个素材库页面，能列出、筛选、预览、下载站点用到的图片。
2. 每张图都能看出：来源（随代码 / 上传）、用途、被哪些页面或配置引用、大小、尺寸、上传时间。
3. 页面上需要换图的位置，可以从素材库选一张，而不是每处各自上传。
4. 本地登记过的素材，可以用脚本迁到生产对象存储，并写入生产库。

## 不做

- 不做图片编辑（裁剪、滤镜、压缩参数）。
- 不做公开的素材浏览页。素材库只在管理端。
- 不替代 AI 资产页面。用户自己的 AI 图仍按归属在用户端查看；素材库只读、不改归属。
- 不在第一版接视频、PDF 等非图片文件。

## 分两步

### 第一版：只读管理页

现有能力已经够用：`file_assets` 表、`/api/v1/app/uploads` 上传链路、公开签名 URL、管理端 `ImageFileField`。

- 管理端新页面，按 `purpose`（`COVER`、`AI_ASSET`）和时间分页列出 `READY` 的图片，带缩略图、大预览和下载。
- 随代码提交的占位图从 `publicImageCatalog.json` 读出来，标为「随代码发布」，只读。
- 支持复制地址、查看引用位置（项目配置哪个端、哪篇内容）。
- 不新建表，不改上传协议。

需要新增的是一个管理端只读列表接口，带权限码与数据范围，分页有上限。

### 第二版：页面从素材库选图

- 首页、项目页等位置改成引用素材 ID，配置里存文件 ID，公开接口照旧换成短期签名 URL。
- 可能需要一张引用表或在素材上记标签，等第一版用一段时间再定。
- SVG 现在被上传策略拒绝（`file-policy.ts` 的 denylist 含 `image/svg+xml`）。随代码的 SVG 要进素材库，有两种做法，届时二选一：
  - 发布前导出成 webp / png 再上传；
  - 单独放开受信管理员上传 SVG，并补上内容嗅探和净化。默认不放开。

## 占位图和包体积

`public/` 里的文件不会打进 JavaScript 包，构建时原样拷进 `dist`，浏览器按需请求。当前 8 张占位图合计约 10 KB，不影响首屏脚本。真实照片、截图不要再放进 `public/`，走上传，进对象存储。

## 生产迁移

生产没有本地上传过的图。做素材库时补一个一次性脚本：

1. 读取本地登记的素材清单（随代码清单加上本地 `file_assets` 的导出）。
2. 按生产的上传链路逐个上传，得到生产的文件 ID。
3. 把本地文件 ID 映射到生产文件 ID，更新引用它们的配置（例如 `site.layout.projectVisualAssets`）。
4. 可重复执行：已经迁过的按 sha256 跳过。

本地之后再加的图，是否迁移由人工决定，不自动同步。

## 预览下载（已在 `home-showcase` 落地）

能点开看大图的地方都要有下载按钮。当前用户端项目封面、正文图片、AI 图片的大图工具条已经加了下载（`apps/user-web/src/components/shared/imagePreviewActions.tsx`）。素材库的大图预览沿用同一个下载动作。
