# 二期想法：PDF / Word 站内编辑器

> 状态：想法，不进 Nest M5
> 最后更新：2026-09-08

## 一期（当前）

- PDF：上传、PDF.js 预览、阅读、下载；**不内建编辑器**。改文件用外部工具后再上传新版本。
- Word：`.docx` 上传、现有 docx 预览、下载；**不接编辑器**。

## 二期想法

| 类型 | 想法 | 未决 |
| --- | --- | --- |
| PDF | 是否引入 OnlyOffice / 同类协作套件；或继续「外部编辑 + 重新上传」 | 成本高，不一定做站内编辑 |
| Word | 打开 / 编辑 / 保存回写 / 版本快照 | 编辑器选型（OnlyOffice、自研、转 Markdown）未定 |

一期 `ContentType.PDF` / `WORD` 只作为文件型内容，主文件走 `primaryFileId`。二期若做编辑器，再单独写 PRD，不要改一期「预览即完成」的验收。
