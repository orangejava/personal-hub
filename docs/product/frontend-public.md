## 导航结构

```
公开前台导航（顶部固定）
├── Logo（左）
├── 首页
├── 内容中心
├── AI 工具中心
├── 项目 / 作品
├── 关于我
└── 右上角：未登录→[登录 / 注册]  已登录→[头像 ▾（进入工作区 / 退出）]
```

- 导航/菜单配置**只在后台管理**中操作
- 公开顶栏文案使用接口菜单的 `name`（中文默认展示名），**不随浏览器语言切换成英文**。`localeKey` / `routeKey` 不是顶栏文案，约定见 [系统配置与菜单 PRD §4.3.1](../prd/long-term/system-config-menu-prd.md)
- 滚动时导航栏背景从透明变为毛玻璃效果（blur + 半透明白）
- 移动端收起为汉堡菜单

## 首页 `/`

### 整体风格方向

- 简洁、技术感，深色/浅色主题跟随系统
- 第一屏满屏（Hero），向下滚动进入各区块

### 区块布局（从上到下）

#### 1. Hero 区块（首屏，必须）

```
[头像]  Hi，我是 {name} 👋
        一句话介绍（职业/方向）
        [查看作品]  [AI 工具]
```

- 头像圆形，右侧或左侧排列（响应式）
- 背景：轻微渐变或抽象几何图形

#### 2. 内容推荐区块（可配置显隐 + 排序）

- 标题："最近分享"
- 算法：**手动精选优先，无精选内容时取最新发布的 6 篇**
- 展示：卡片网格（PC 3列，平板 2列，手机 1列）
- 卡片内容：封面图、标题、类型标签、摘要（2 行截断）、发布日期

#### 3. AI 工具推荐区块（可配置显隐 + 排序）

- 标题："AI 工具"
- 展示：横向卡片列表（每行最多 4 个），不分页
- 卡片内容：工具图标、名称、一句话简介、[立即使用] 按钮

#### 4. 技术栈简介区块（可配置显隐）

- 简短说明技术兴趣方向，图标列表展示主要技术栈
- 数据来源：后台系统配置

## 内容中心 `/content`

### 列表页

- **顶部筛选栏**：
  - 分类（树形下拉，支持多级）
  - 标签（多选 Tag 样式）
  - 类型（全部 / 掘金小册 / PDF / Word / Markdown / 富文本）
  - 搜索框（回车或点击搜索）
- **列表排序**：最新发布 / 最多阅读（默认最新）
- **布局切换**：卡片视图（默认）/ 列表视图
- **分页**：每页 12 条，滚动分页（Intersection Observer 懒加载）

**卡片内容**：封面图（无封面则展示类型色块占位）、类型标签、标题、摘要（3行截断）、阅读数、发布日期、[收藏] 按钮（登录后显示）

### 内容阅读页 `/content/:id`

#### 通用布局

```
┌──────────────────────────────────────────────────────┐
│  面包屑：内容中心 > {分类} > {标题}                    │
├──────────┬───────────────────────────────────────────┤
│  目录    │  正文区域                                   │
│ （左侧，  │  标题、元信息（类型/日期/作者）              │
│  固定）   │  正文内容                                   │
│          │                                            │
│          │  底部操作栏：[收藏] [复制链接] [引用到AI]    │
└──────────┴───────────────────────────────────────────┘
```

#### 各格式阅读页交互

**掘金小册**：

- 最左侧：当前用户可访问的小册列表
- 左侧：当前小册的章节目录（树形，当前章节高亮）
- 中间：章节正文
- 右侧：当前章节标题目录（`h2/h3/h4`）
- 章节间 [上一章] [下一章] 导航
- 顶部显示整体阅读进度条（第 X / 共 Y 章）
- 正文 Markdown 渲染，代码块含语言标识和一键复制

**PDF**：

- 使用 PDF.js 内嵌渲染，支持翻页、缩放
- 顶部显示页码（第 X / Y 页）
- 支持全屏阅读模式
- 保留阅读与下载，不在站内提供复杂 PDF 编辑

**Markdown**：

- 渲染为 HTML，代码块高亮（shiki）
- 右侧目录（`h2`/`h3` 提取，滚动联动高亮）
- 代码块一键复制
- 编辑在工作区的 Markdown 工具页完成

**富文本文章**：

- 直接渲染 HTML（Tiptap 输出）
- 右侧目录同 Markdown
- 编辑与协作在工作区富文本工具页完成

**Word**：

- 公开前台保留查看 / 阅读能力
- 支持基础目录和分页预览（具体渲染方式实现时确定）
- 编辑与下载入口在登录后的工作区中提供

#### 公共功能

- **收藏**：已收藏显示实心星标，点击切换，未登录引导登录
- **引用到 AI**：点击后跳转 AI Chat 页，并自动将该内容作为上下文注入
- **阅读进度保存**：登录用户下次打开自动恢复滚动位置（仅掘金小册/PDF）

## 项目 / 作品 `/projects`

### 页面设计

- **布局**：时间线 + 卡片混合（左侧时间轴，右侧卡片）
- **排序**：时间倒序

### 卡片内容

```
┌────────────────────────────────────────────────┐
│ [封面截图 / 项目图标]                            │
│ 项目名称                                         │
│ 标签：[开源] [React] [NestJS]                   │
│ 一句话描述                                       │
│ [GitHub ↗] [在线预览 ↗]                         │
└────────────────────────────────────────────────┘
```

### 数据来源

- **手动维护**：通过后台内容管理录入（类型 = `project`，首版方案）
- **GitHub 集成**（后续）：调用 GitHub API 同步 Star 数、语言、最后更新时间

### 首版内容优先级

1. 本项目（personal-hub）本身
2. 学习过程中的练习项目
3. 开源贡献（如有）

## 账户入口（右上角）

| 状态   | 展示                                           |
| ------ | ---------------------------------------------- |
| 未登录 | [登录] [注册] 两个按钮                         |
| 已登录 | 头像 + 昵称（最多显示 8 字），点击展开下拉菜单 |

### 下拉菜单（已登录）

- 进入工作区（→ `/workspace`）
- 个人设置（→ `/workspace/profile`）
- 退出登录

### 登录/注册弹窗

- 弹窗形式（不跳转页面），支持登录/注册 Tab 切换
- 注册完成后自动登录并关闭弹窗

## 导航结构

```
公开前台导航
├── 首页
├── 内容中心
├── AI 工具中心
├── 项目 / 作品
├── 关于我
└── [右上角] 账户入口（登录 / 注册 / 进入工作区）
```

- 内容中心与 AI 工具中心为**并列一级入口**
- 导航/菜单配置**只在后台管理**中操作，不作为前台能力暴露
- 顶栏展示中文 `name`，不随浏览器语言变成 Home / Content（见 [菜单 PRD §4.3.1](../prd/long-term/system-config-menu-prd.md)）
