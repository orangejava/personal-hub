# 登录后工作区

> 状态：🟢 产品与 UI 说明；未来数据、权限和接口以 Canonical 后端文档为准，当前 React-first mock 仅用于验证体验
> 最后更新：2026-09-09

---

## 定位

登录用户进入后的专属功能区。当前 UI 可按 mock 角色呈现不同菜单；未来 Nest 只接受单角色和 Canonical 权限码，并在服务端执行 `OWN/ALL` 数据范围。

与公开前台共用同一套 Next.js 工程，但使用**独立布局**（左侧边栏 + 顶部栏），路由前缀为 `/workspace`。

在新的语义里，工作区不只是“我的内容”，而是：

- 文档资源管理区
- 创作与编辑工具区
- 小册管理区
- AI 与个人功能区

## 文档管理页 `/workspace/content`

详细 PRD 见 [content-workspace-prd.md](../prd/react-first/content-workspace-prd.md)。

### 列表页设计

- **筛选栏**：类型（全部 / 小册 / PDF / Word / Markdown / 富文本 / 外链）、状态（草稿 / 已发布 / 已归档）、关键字搜索
- **列表列**：封面缩略图、标题、类型标签、状态徽章、更新时间、操作
- **操作项**：编辑信息（标题/分类/摘要/可见性）、编辑正文（仅 Markdown / 富文本）、查看、发布、归档、删除
- PDF / Word / 小册没有站内正文编辑器，发布前用「编辑信息」补齐标题和分类
- ZIP 导入的小册会打「待审公开」标签（仅版权闸、尚未允许公开）；编辑者提交发布后打「待审核」
- **发布规则**：编辑者（`content:publish` OWN）点发布 = 提交审核，内容保持草稿；所有者/管理员（ALL）即时发布。导入内容要变成公开/登录可见时，所有者弹窗填版权说明，编辑者由后台审核通过时填写
- **空状态**：展示插图 + "添加你的第一份文档" + [立即创建] 按钮

### 新建页约束（已落地）

- Markdown / 富文本 / PDF / Word：标题、分类在创建时必填（后端创建接口仍允许空，发布时强制校验）
- 小册：分类必填；标题可留空。选 ZIP 后会从 `meta.json`（没有则用文件名）反填标题和摘要，仅作预览
- 小册 ZIP 导入成功后，标题以 ZIP 解析结果为准，**不会**用表单标题覆盖；只会把分类写入草稿，摘要仅在用户主动填写时 PATCH
- 导入任务在服务端排队；新建页仍会轮询约 60 秒。关掉页面不会取消任务，可到 `/workspace/uploads` 继续看进度、失败原因并重试失败的小册导入
- 导入小册强制 `DRAFT + PRIVATE + PRIVATE_UNTIL_LICENSED`。作者不能自己清闸；公开须走内容审核（或所有者直接发布并填写版权说明）

## 上传任务 `/workspace/uploads`

- 下拉筛选默认 **全部**，可筛 **小册导入 / PDF / Word**
- PDF/Word 不是 mock：新建内容时预签名上传会写入 `file_assets`（`CONTENT_FILE` + PDF/Word MIME），所以列表里能看到；未完成的 ZIP 不会出现在这里
- 删除：只把该条从任务列表隐藏（`hiddenFromTaskList`），不删文档、不删源文件
- 列表：`GET /app/upload-tasks` 服务端按 `createdAt` 真分页，默认 `pageSize=10`，不接受 `mimeKind`；可选 `taskKind` 由服务端过滤
- 类型下拉走 `taskKind`；仅当存在 `QUEUED` / `VALIDATING` / `IMPORTING` 时轮询，标签隐藏时暂停
- 失败小册可 `POST /app/booklet-imports/:jobId/retry`（重置同一任务，不新建内容）；`DELETE` 只隐藏列表项
- 新建页轮询保留；离开后在本页继续看进度

### 页面定位说明

- 这里负责“文档资源库”的统一管理
- 不再承担所有编辑器入口的语义
- 专项编辑器和小册工具有各自独立页面

### 文档创建与编辑入口

统一入口仍可保留，但在产品语义上拆成两类：

- 文档型入口：上传、发布、查看、归档
- 工具型入口：Markdown 编辑器、Word 编辑器、富文本协作、小册管理

### 通用创建流程（用于资源入库）

分步骤向导：

```
Step 1  选择内容类型
        [小册导入]  [PDF 上传]  [Word 上传]  [Markdown]  [富文本]  [外部链接]

Step 2  填写基本信息
        · 标题（创建必填；发布必须 1～200 字）
        · 封面图（可选，支持上传或粘贴 URL，建议 16:9）
        · 分类（创建必填；发布必须选择有效分类）
        · 标签（多选，可输入创建新标签）
        · 摘要（可选，不填时系统自动截取前 200 字）
        · 可见性（public / login / private，默认 login）

Step 3  输入内容
        · 小册：上传 ZIP 包，解析后生成章节结构
        · PDF：拖拽上传区，上传后显示首页缩略图预览
        · Word：上传 `.docx`，进入 Word 编辑器继续编辑
        · Markdown：进入 Markdown 编辑器，支持预览按钮
        · 富文本：进入 Textbus 编辑器
        · 外部链接：URL 输入框 + 来源说明（选填）

Step 4  保存
        [保存为草稿]  [直接发布]
```

## 小册管理页 `/workspace/booklets`

详细 PRD 见 [content-workspace-prd.md](../prd/react-first/content-workspace-prd.md)。

### 功能目标

- 上传掘金小册
- 下载掘金小册
- 管理当前用户可访问的小册
- 从管理页直接进入阅读

### 页面布局

```
┌─────────────────────────────────────────────────────┐
│ 顶部操作区：[上传小册] [批量下载] [搜索]              │
├──────────────┬──────────────────────────────────────┤
│ 左侧小册列表  │ 右侧详情区                             │
│ 书名 / 状态   │ · 小册封面                             │
│ 作者 / 更新时间│ · 简介                                │
│              │ · 章节数量                             │
│              │ · 操作：[打开阅读] [下载] [编辑信息]    │
└──────────────┴──────────────────────────────────────┘
```

### 关键规则

- 当前 React mock 的上传/下载按钮保留；未来上传先创建 `/api/v1/app/uploads` 会话，导入由 `/app/booklet-imports` 异步处理。
- 小册导入需要 `booklet:import` 加 `OWN/ALL`，不是仅登录即可上传。
- 导入小册默认 `DRAFT + PRIVATE + private_until_licensed`；上传者/管理员可验证章节结构，其他用户不能因发布状态取得访问权。
- 仅管理员在内容审核通过（或所有者直接发布）并留下版权说明后，导入小册才可对其他用户开放阅读或源文件下载。
- 阅读页左侧可切换不同小册，不需要先退回列表页

## 个人设置页 `/workspace/profile`

### 基本信息 Tab

- 头像（点击上传，支持裁剪，最大 2MB）
- 昵称（必填，最多 20 字）
- 个人简介（选填，最多 200 字）
- [保存] 按钮

### 账号安全 Tab

- 显示注册邮箱（只读）
- 修改密码（需输入旧密码 → 新密码 → 确认新密码）
- 修改邮箱：需当前密码并完成新邮箱验证；成功后撤销其他会话。
- 管理角色可在此设置中自愿绑定/停用 TOTP；绑定确认时恢复码只展示一次。
- [修改密码] 按钮

### 第三方绑定 Tab（后续版本）

- GitHub / 微信 绑定/解绑入口（首版仅展示入口，标注"即将上线"）
