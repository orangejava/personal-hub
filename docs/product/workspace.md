# 登录后工作区

> 状态：🟢 产品与 UI 说明；未来数据、权限和接口以 Canonical 后端文档为准，当前 React-first mock 仅用于验证体验
> 最后更新：2026-08-02

---

## 定位

登录用户进入后的专属功能区。当前 UI 可按 mock 角色呈现不同菜单；未来 Nest 只接受单角色和 Canonical 权限码，并在服务端执行 `OWN/ALL` 数据范围。

与公开前台共用同一套 Next.js 工程，但使用**独立布局**（左侧边栏 + 顶部栏），路由前缀为 `/workspace`。

在新的语义里，工作区不只是“我的内容”，而是：

- 文档资源管理区
- 创作与编辑工具区
- 小册管理区
- AI 与个人功能区

## 文档管理页 `/workspace/content`

详细 PRD 见 [content-workspace-prd.md](../prd/react-first/content-workspace-prd.md)。

### 列表页设计

- **筛选栏**：类型（全部 / 小册 / PDF / Word / Markdown / 富文本 / 外链）、状态（草稿 / 已发布 / 已归档）、关键字搜索
- **列表列**：封面缩略图、标题、类型标签、状态徽章、更新时间、操作
- **操作项**：编辑、查看（跳转阅读页）、切换可见性（public/login/private）、归档、删除
- **空状态**：展示插图 + "添加你的第一份文档" + [立即创建] 按钮

### 页面定位说明

- 这里负责“文档资源库”的统一管理
- 不再承担所有编辑器入口的语义
- 专项编辑器和小册工具有各自独立页面

### 文档创建与编辑入口

统一入口仍可保留，但在产品语义上拆成两类：

- 文档型入口：上传、发布、查看、归档
- 工具型入口：Markdown 编辑器、Word 编辑器、富文本协作、小册管理

### 通用创建流程（用于资源入库）

分步骤向导：

```
Step 1  选择内容类型
        [小册导入]  [PDF 上传]  [Word 上传]  [Markdown]  [富文本]  [外部链接]

Step 2  填写基本信息
        · 标题（草稿可为空或临时标题；发布必须 1～200 字）
        · 封面图（可选，支持上传或粘贴 URL，建议 16:9）
        · 分类（草稿可为空；发布必须选择有效分类）
        · 标签（多选，可输入创建新标签）
        · 摘要（可选，不填时系统自动截取前 200 字）
        · 可见性（public / login / private，默认 login）

Step 3  输入内容
        · 小册：上传 ZIP 包，解析后生成章节结构
        · PDF：拖拽上传区，上传后显示首页缩略图预览
        · Word：上传 `.docx`，进入 Word 编辑器继续编辑
        · Markdown：进入 Markdown 编辑器，支持预览按钮
        · 富文本：进入 Textbus 编辑器
        · 外部链接：URL 输入框 + 来源说明（选填）

Step 4  保存
        [保存为草稿]  [直接发布]
```

## 小册管理页 `/workspace/booklets`

详细 PRD 见 [content-workspace-prd.md](../prd/react-first/content-workspace-prd.md)。

### 功能目标

- 上传掘金小册
- 下载掘金小册
- 管理当前用户可访问的小册
- 从管理页直接进入阅读

### 页面布局

```
┌─────────────────────────────────────────────────────┐
│ 顶部操作区：[上传小册] [批量下载] [搜索]              │
├──────────────┬──────────────────────────────────────┤
│ 左侧小册列表  │ 右侧详情区                             │
│ 书名 / 状态   │ · 小册封面                             │
│ 作者 / 更新时间│ · 简介                                │
│              │ · 章节数量                             │
│              │ · 操作：[打开阅读] [下载] [编辑信息]    │
└──────────────┴──────────────────────────────────────┘
```

### 关键规则

- 当前 React mock 的上传/下载按钮保留；未来上传先创建 `/api/v1/app/uploads` 会话，导入由 `/app/booklet-imports` 异步处理。
- 小册导入需要 `booklet:import` 加 `OWN/ALL`，不是仅登录即可上传。
- 导入小册默认 `DRAFT + PRIVATE + private_until_licensed`；上传者/管理员可验证章节结构，其他用户不能因发布状态取得访问权。
- 仅管理员记录授权说明并解除导入限制后，才可对其他用户开放阅读或源文件下载。
- 阅读页左侧可切换不同小册，不需要先退回列表页

## 我的收藏页 `/workspace/favorites`

- 展示用户收藏的全部内容（跨类型）
- 列：封面、标题、类型、收藏时间、操作（取消收藏 / 阅读）
- 筛选：按类型、关键字搜索
- 支持批量操作（多选 → 批量取消收藏）
- 空状态：引导去内容中心浏览

---

## AI 对话历史页 `/workspace/ai/history`

- 以列表展示历史会话
- 列：会话标题（自动取首条消息前 20 字）、使用模型、最后更新时间、操作
- 操作：继续对话（跳转 AI Chat 页并加载上下文）、重命名、删除
- 支持关键字搜索（匹配会话标题）
- 支持批量删除
- 空状态：引导去 AI Chat 工具页开始第一次对话

## 个人设置页 `/workspace/profile`

### 基本信息 Tab

- 头像（点击上传，支持裁剪，最大 2MB）
- 昵称（必填，最多 20 字）
- 个人简介（选填，最多 200 字）
- [保存] 按钮

### 账号安全 Tab

- 显示注册邮箱（只读）
- 修改密码（需输入旧密码 → 新密码 → 确认新密码）
- 修改邮箱：需当前密码并完成新邮箱验证；成功后撤销其他会话。
- 管理角色可在此设置中自愿绑定/停用 TOTP；绑定确认时恢复码只展示一次。
- [修改密码] 按钮

### 第三方绑定 Tab（后续版本）

- GitHub / 微信 绑定/解绑入口（首版仅展示入口，标注"即将上线"）

## 角色功能差异

| 功能页面                     |          普通会员 (Member)           |  编辑者 (Editor)  |  管理员 (Admin)   |
| ---------------------------- | :----------------------------------: | :---------------: | :---------------: |
| 工作台仪表盘                 |                  ✅                  |        ✅         |        ✅         |
| 我的收藏                     |                  ✅                  |        ✅         |        ✅         |
| AI 对话历史                  |                  ✅                  |        ✅         |        ✅         |
| 我的用量                     |                  ✅                  |        ✅         |        ✅         |
| 个人设置                     |                  ✅                  |        ✅         |        ✅         |
| 文档管理（查看列表）         |          按 `content:read`           | 按 `content:read` | 按 `content:read` |
| 小册管理（查看 / 下载）      |             按内容可见性             |   按内容可见性    |   按内容可见性    |
| 小册导入                     |  仅具备 `booklet:import` + OWN/ALL   |       同左        |       同左        |
| Markdown / Word / 富文本编辑 | 按 `content:create/update` + OWN/ALL |       同左        |       同左        |
| 进入后台 `/admin`            |                  ❌                  |        ❌         |        ✅         |

> 角色由管理员在后台单选分配，用户不可自行申请升级（首版）。最终授权由服务端 Canonical 权限和数据范围决定，表格仅表达 UI 入口策略。
