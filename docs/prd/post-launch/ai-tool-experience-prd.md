# 主目录工具栏与工具页体验优化 PRD

> 状态：需求细化稿；顶栏一级入口、双浏览模式、文本对比首版和 Cesium 展示入口已确认；与现有 AI 工作台和 `ai-admin` 独立
> 最后更新：2026-10-29
> 关系：细化公开前台独立工具入口、文本内容对比与 Cesium 3D 地图展示入口；不改变现有 AI 路由

## 1. 目标

在公开前台顶栏增加与“首页”“内容中心”“AI”同级的“工具”入口。工具中心承载独立的非 AI 工具；首版完成文本内容对比，同时为学习和项目展示性质的 Cesium 3D 地图保留入口。不改变现有 `/ai` 工作台及其导航。

## 2. 主目录工具栏

### 2.1 信息结构

- 公开前台顶栏新增“工具”一级入口，和“首页”“内容中心”“AI”并列。点击进入独立工具中心，建议路由 `/tools`；顶栏实际名称仍遵循后台菜单的 `name` 约定。
- 工具栏中的工具与 AI 工作台分开管理、分开路由、分开权限和分开验收。
- 每个工具入口至少展示名称、简短说明、图标或缩略图、启用状态和跳转地址。
- 未上线工具可以展示“规划中/暂不可用”，点击后给出明确状态，不进入不存在的页面。
- 工具栏在手机和平板使用现有紧凑导航或抽屉模式，不能依赖 hover 或横向滚动。工具中心内部的目录与卡片切换见第 3 节。

### 2.2 工具配置

- 工具栏配置至少包含 `key`、名称、说明、图标、路由、排序、是否启用和登录要求。
- 后台是否需要配置由工具数量和运营需求决定，第一版可以先使用代码配置。
- 工具入口不直接承担工具业务数据；最近记录、历史、资产和任务由具体工具页面决定。

### 2.3 当前工具清单

| 工具 | 入口定位 | 第一版范围 | 状态 |
| --- | --- | --- | --- |
| 文本内容对比 | 可直接使用的独立工具 | 匿名本地对比；登录用户主动保存并查看历史；纯文本、HTML、CSS、JSON 等源码模式 | 首版交互见第 5、8 节 |
| Cesium 3D 地图 | 学习与项目展示入口 | 显示工具介绍、学习方向和未来作品入口；地图练习及项目内容后续逐步加入 | 首版只做可访问的展示/占位页 |

文本内容对比不属于 `/ai` 工作台，也不读取 AI 会话、AI 生成任务或用户素材库作为默认数据源。第一版支持直接粘贴文本、按行比较并高亮行内字符差异。文件导入与差异文件导出后置；登录后保存历史纳入首版。

### 2.4 工具栏展示顺序

- 当前展示“文本内容对比”和“Cesium 3D 地图”；Cesium 页面需清楚标注学习展示状态，不伪造已完成的地图能力。不得增加 AI Chat/Text/Image/Video 入口。
- 后续新增工具时，按产品确认的分组和排序扩展配置；未确认前不改变现有 AI 导航结构。

### 2.5 统一交互

- 工具页面沿用项目公共布局、状态反馈和响应式规则。
- 入口按钮、返回主目录、登录拦截、加载、空状态、失败状态和暂不可用状态保持一致。
- 本文件第 5、8、11 节定义文本对比的输入、结果与历史；后续新增工具再按需要单独细化，不强加统一业务模型。

## 3. 工具页通用约束

### 3.1 两种浏览模式

- 工具中心有“目录模式”和“卡片模式”切换，首次进入默认目录模式；用户切换偏好只保存**布局模式**到本地，不保存工具输入。卡片模式的 `/tools` 展示工具卡片；目录模式的 `/tools` 展示左侧常驻目录和右侧选中工具，默认选中首个已上线工具。模式切换不自动清空当前输入或重跑计算。
- 每个工具有独立的内容路由（建议 `/tools/text-diff`、`/tools/cesium-map`）和单一工具内容组件。目录模式使用显式 `?view=directory`（例如 `/tools/text-diff?view=directory`），在宽屏用左侧目录包裹该组件；卡片进入或无 `view` 的内容深链接显示纯净工具页。避免为两种模式复制两份业务页面。
- 目录模式里切换工具时更新 URL 和选中项；浏览器后退能返回上一个工具/中心页。卡片进入的纯净页有可见“返回工具”按钮，优先返回 `/tools` 的卡片视图；若从其它来源直接打开，则返回 `/tools`，不依赖不可信的浏览器历史。纯净页的正文有适合内容的最大宽度，目录模式在同一宽度基础上扣除侧栏空间，不把表单挤成窄列。
- 宽屏左侧目录和右侧工具区同时展示。窄屏目录收起，工具内容以纯净页显示；切换工具通过“工具目录”抽屉或返回中心页完成，不使用横向滚动容纳侧栏。卡片页在窄屏改为单列/合适列数，不让卡片和工具页产生页面级横向溢出。
- 模式与工具选择是两个状态：切换模式时保留当前工具；从目录切到卡片回到工具卡片列表，再点击卡片进入纯净工具页。页面存活期间的输入草稿放在工具级内存状态，切换布局不丢失；刷新后不恢复敏感输入。从纯净页返回时恢复卡片列表。路由刷新后从 URL 还原当前工具和显式目录状态，从本地布局偏好还原中心页的目录/卡片。

| 地址/入口 | 宽屏呈现 | 窄屏呈现 | 返回按钮 |
| --- | --- | --- | --- |
| `/tools` | 按本地布局偏好进入目录或卡片；首次默认目录并选中文本对比 | 目录偏好仍有效，但侧栏变为“工具目录”抽屉 | 中心页不显示“返回工具” |
| `/tools?view=cards` | 工具卡片 | 单列/自适应卡片 | 中心页不显示“返回工具” |
| `/tools/:key?view=directory` | 左侧目录 + 右侧该工具 | 纯净工具内容 +“工具目录”抽屉 | 返回 `/tools?view=directory` |
| `/tools/:key` | 纯净工具内容 | 纯净工具内容 | 返回 `/tools?view=cards` |

显式 URL 的 `view` 优先于本地布局偏好；无效工具 key 显示工具中心可返回的 404/暂不可用状态。模式切换与卡片跳转更新 URL，浏览器后退按 URL 恢复布局；工具级内存草稿由 `/tools` 路由层持有，离开工具区或刷新即清除。这样既保持两种入口共用内容，又不把对比正文持久化到本地。

### 3.2 公共规则

- 每个工具页面自行定义输入、处理、结果、保存和错误状态；沿用项目公共顶栏、主题、反馈、按钮与焦点样式。文本对比首版无 AI 额度限制。
- 需要登录、文件权限或额度的未来工具，在入口和页面内都执行一致的服务端校验。工具页面未来可接入工作区素材库，但不能把素材库业务状态嵌进工具导航。
- 页面按项目视口档适配：手机 `<= 767px`、平板 `768–991px`、桌面 `>= 992px`；侧栏能否常驻还需根据工具内容的实际最小宽度判断，不仅凭桌面阈值。至少检查 `390px`、`430px`、`768px`、`1440px` 和矮屏 `<= 499px`。

## 4. 数据和接口边界

- 工具栏只读取工具入口配置，不聚合 AI 会话、AI 任务或 AI 资产。
- 文本比较运算在浏览器内执行；匿名用户不调用对比/历史接口。登录用户主动保存历史时才调用本站鉴权接口，服务端必须按用户隔离；读取、删除历史同样鉴权。具体 API/数据模型在实施时同步 Canonical 契约，不借用 AI 会话接口。
- 主目录不暴露内部文件 ID、用户私有数据或工具内部任务状态。

## 5. 文本内容对比可执行细节

- 建议路由 `/tools/text-diff`，入口名称“文本内容对比”。匿名可直接使用，对比运算仅在当前浏览器内存中进行；登录用户的运算也保持本地，只有主动点“保存到历史”才上传这次对比快照。保存前明确提示将原文、新文本、模式及差异摘要存入账号；不自动保存，也不采集正文埋点。登录用户打开已保存历史时才从服务端读取该条快照，这属于明确的历史查看动作。
- 输入模式提供“纯文本”“HTML”“CSS”“JSON”，后续可增加 Markdown、JavaScript 等源码模式。四种模式都先对**源码文本**做差异对比；HTML 不渲染或执行，CSS 不注入页面，JSON 不执行。模式负责语法高亮、文件类型提示和可选的显式格式化，不改变默认比较语义。JSON 格式化仅在两侧均可解析时由用户主动触发，格式化后的对比需明确标记；非法 JSON 仍可按原文比较并提示格式错误。切换模式保留原输入，旧结果标记需重新比较。
- 左侧“原文”、右侧“新文本”，建议各自最多 200,000 字符；超限禁用比较并提示。按钮为“比较”“交换左右”“清空”“复制差异摘要”。两侧空白时显示使用提示；单侧为空时另一侧全部判为新增或删除。字符上限属于性能草案，需在目标设备实测后冻结。
- 建议默认按行比较，再在相邻替换行内按字符高亮；空格、换行参与比较，不自动 trim 或格式化，保留用户输入。结果分别显示新增、删除、修改、未变化的行数，并提供并排/上下两种视图。大文本处理交给 Web Worker 或等效异步方案，输入时不逐字重算；用户点击“比较”才启动，可取消上一次计算。算法对大规模重复行的内存和运行时间要有硬限制，超出时降为仅按行比较并提示，不能卡死主线程。
- 结果区中的用户文本只按纯文本渲染，不作为 HTML 插入。长行在单条差异内部滚动或换行，不能把手机页面撑宽；复制结果采用纯文本摘要，不含用户输入全文。
- 手机档用上下视图作为默认；桌面默认并排。切换视图不重新计算。刷新后输入清空，离开页面前若有未复制结果不强制弹窗阻断。

## 6. 后续范围与实施阈值

- 文件导入、差异文件导出、Markdown/富文本结构化比较、跨设备草稿自动同步和 Cesium 地图练习功能。保留未来文件导入的输入适配层入口，但本期不出现可点击的“上传文件”控件。
- 后台工具运营配置、独立统计、后续工具分组和排序。首版工具清单可走现有公开菜单加代码注册表，不新增工具专属后台配置页；顶栏菜单仍遵循后台菜单权限与启用状态。
- 登录用户主动保存的历史**不自动过期，保留到用户主动删除**；首版提供删除单条和清空自己的历史，服务端不得向其它用户返回记录。单条大小和总容量需设技术上限，达到上限时拒绝新增并提示用户先删除，不得静默淘汰旧记录；导出策略后置。

## 7. 验收标准

- 公开前台顶栏能看到与首页、内容中心、AI 同级的“工具”；目录/卡片两种中心视图能切换，工具深链接和返回路径正确。
- 工具入口在手机、平板和桌面均能访问，不出现横向溢出或 hover 才能操作的入口。
- 工具启用、禁用、登录拦截和暂不可用状态表现一致。
- 工具栏只负责入口和导航，不读取或混入 AI 会话、AI 任务和 AI 资产数据。
- 展示“文本内容对比”和“Cesium 3D 地图”入口；后者说明学习与项目展示状态，不把现有 AI 页面误归入工具中心。
- 两份文本在纯文本、HTML、CSS、JSON 模式下的新增/删除/修改/未变化统计与差异高亮正确；空输入、非法 JSON、超限、长单行、快速重复比较、手机视口均有可用反馈。匿名使用及未主动保存时，原文不会出现在网络请求体或应用日志中。
- 登录用户主动保存后能在自己的历史里打开和删除记录；退出登录后历史不可见，跨用户请求被拒绝。保存失败保留当前输入并可重试，不产生重复记录。

## 8. 文本对比页面流程与边界

| 状态 | 页面行为 |
| --- | --- |
| 初始 | 双输入区、简短示例与隐私提示；不自动填入用户剪贴板 |
| 已输入未比较 | 显示字符/行数和可用操作；旧结果标“输入已变化，需重新比较”，不能冒充当前结果 |
| 计算中 | 显示处理状态与取消按钮；再次点击比较取消旧任务并以新快照计算 |
| 有结果 | 顶部汇总、差异导航、并排/上下视图、复制摘要；用户原文始终可编辑 |
| 过大或异常 | 保留输入，说明限制或失败原因；可退回仅按行比较，不清空内容 |
| 登录且主动保存 | 显示保存中与结果反馈；成功后历史可打开，失败保留本地输入与结果并允许重试 |

比较的“修改行”只作为相邻删除/新增行的**展示配对**，不能让统计因配对算法改变原始差异；结果摘要需说明新增、删除、配对修改的口径。空行、CRLF/LF、末尾换行、制表符、连续空格、Unicode 组合字符和 emoji 都要有用例。建议文本不做 Unicode 归一化、不忽略大小写、不忽略空白；若后续增加选项，应把选项写在结果摘要中，避免误读。复制摘要只含计数与设置，若用户需要复制具体差异，另提供“复制所选差异”且明确会复制输入内容。

桌面并排时两个结果面板的纵向滚动同步定位到同一差异块，但用户可暂时解除同步独立查看；长行采用面板内部换行/滚动设置，不让页面整体横向溢出。手机默认上下视图，两个输入区可折叠，差异导航和按钮在手指可点范围，软键盘弹起不能遮挡比较按钮。文本输入框允许键盘快捷键，但不得覆盖浏览器常用复制、撤销或搜索快捷键。离开整个工具区或刷新时清空未保存的内存草稿；在目录/卡片模式间切换不清空。无需强制离开确认，页面可提示“文本仅在本页保留”。

工具入口卡片/栏目仅负责导航：名称、说明、图标、可用状态。第一版只有两项时不强行造分类、搜索框、推荐算法或后台运营接口；后续达到多项再增加分类和排序。停用时已有深链接应显示可理解的“暂不可用”页面，不能 404 或跳到 AI。每个工具未来可单独决定是否登录/上传/调用后端，不继承 AI 额度和会话模型。

## 9. 数据安全、性能与可访问性验收

- 对比运行在浏览器内；除登录用户主动保存快照这一明确动作外，禁止把正文写入 query、localStorage、错误监控、网络日志和分析事件。用户输入只用文本节点或安全的代码高亮渲染，不使用未经净化的 `innerHTML`；HTML、CSS、JSON 内容一律不执行。剪贴板动作需用户主动触发并有成功/失败反馈。
- Worker 按任务 ID 接受快照并返回结果；输入修改时丢弃旧结果，取消任务后不能被迟到结果覆盖。长文本使用分段渲染或虚拟列表，测量处理耗时、内存和滚动稳定性。建议初始性能目标：典型 10,000 行文本在目标桌面设备 3 秒内给出结果，手机过大时明确降级；正式阈值在样本测试后定。
- 用键盘可依次访问输入区、按钮、差异导航与结果；状态变化用 `aria-live` 通知，新增/删除不能只靠颜色区分。暗色/浅色模式都检查差异文字对比度与选中焦点。
- 验收样本：完全相同、单侧空、行交换、多处重复行、末尾换行差异、中文+emoji、超长单行、200,000 字符边界、快速连续比较、计算中切换视图/离开，HTML 中的脚本标签、CSS 注入样例、合法/非法 JSON、匿名转登录、保存失败和跨用户历史访问。手机 390×844、430×932，平板 768×1024，桌面 1440×900 和矮屏均无页面级横向溢出。

## 10. 推荐实施切片与已确认规则

顶栏一级入口、目录/卡片双模式、匿名本地比较、登录后主动保存历史且**保留到用户主动删除**、首版不导入文件，以及 Cesium 只留学习/作品入口均已确认。每条大小、总条数和性能阈值属于实施压测及存储保护方案，不应误写成入口、功能范围或保留策略尚未确定。

1. 补公开顶栏“工具”入口、`/tools` 中心和两种浏览模式；注册文本对比与 Cesium 展示路由，不碰 `/ai` 路由。
2. 做纯前端文本对比、Worker、四种源码模式、结果视图和测试；再接登录用户的主动保存/查看/删除历史。先用真实样本测性能，再冻结输入上限。
3. 验收路由返回、键盘、手机、暗色/浅色、匿名隐私和账号隔离；文件导入与 Cesium 地图练习进入后续切片。

文件级实施计划需同时覆盖 `apps/user-web/config/routes.ts`、`apps/user-web/src/layouts/PublicLayout.tsx` 及前端公开菜单兜底、两端受控 route registry、`apps/server/src/modules/system/route-registry.ts` 和公开菜单种子；现有导航来自服务端菜单并有前端兜底，只新增页面路由不会让顶栏出现“工具”。登录历史另需 Nest、共享类型、前端 service 和 Canonical API 的同批契约。

## 11. 登录历史的产品与接口边界

- 未登录时不显示“我的历史”，保存按钮提示登录；登录跳转前不把正文放进 URL 或浏览器持久存储。登录回来后若原页面仍存活可继续手动保存，否则用户需重新粘贴。登录用户的比较本身也始终在本地进行。
- “保存到历史”必须由用户点击；保存对象为模式、左右原文、用户可编辑标题、比较设置、摘要、创建时间和结果版本。默认标题可取“文本对比 · 日期时间”，但不能把正文片段作为标题自动泄漏在列表。历史列表只展示标题、模式、时间和统计，不默认加载两份全文；打开某条后再取详情，允许重新比较。
- 保存时使用幂等键避免双击或网络重试产生两条；服务端按当前登录用户隔离列表/详情/删除。匿名用户调用历史接口返回未授权，不能通过猜测 ID 读取他人原文。用户可删单条、清空自己的历史；删除确认说明不可恢复，删除后不再出现在列表。历史内容不进入公开搜索、AI 会话、素材库或管理端普通管理员视图。
- 建议领域接口为“列表、创建、详情、删除、清空”；请求与响应只包含该工具所需字段，具体路径、错误码和容量阈值实施时写入 Canonical API。超过保存上限或服务端故障时只影响保存，不影响本地比较；失败提示不能回显原文。历史不自动到期；数量/大小上限只阻止继续保存，不触发旧记录自动删除，具体阈值经性能和存储测试确定。

## 12. Cesium 3D 地图入口

- 工具中心卡片和左侧目录均显示“Cesium 3D 地图”，说明它是个人学习、练习与项目展示入口。首版页面提供介绍、练习/项目区域的空状态与未来内容位置，不把空页面伪装成已有 3D 地图成果。
- 首版只保留入口与页面结构，不加载 Cesium SDK、地图底图、地形、令牌或大体积资源。后续做实际 3D 练习时再确定 Cesium 版本、底图服务、资源授权、移动端性能和作品数据结构；具体地图交互另立实施切片。
- 目录模式与卡片模式共用这一页面；返回、深链接、暗色/浅色、手机窄屏行为沿用第 3 节。后续作品可分为“练习”和“已完成项目”，首版不产生虚构卡片或假数据。
