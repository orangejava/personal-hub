# 主题、性能与 UI 优化 PRD

> 状态：下一步开发计划
> 最后更新：2026-09-23
> Worktree：主题、性能与 UI
> 计划评分：8.5 / 10
> 关系：承接 `apps/user-web/docs/prd/theme-navigation-config-prd.md` 的后置项，并新增加载速度、Loading 和页面交互优化范围。

## 1. 目标

首版已上线，下一步需要提升面试展示质量和日常使用体验。

本 PRD 覆盖：

- 主题剩余 UI
- 导航布局配置
- Logo / favicon / SEO / 功能开关
- 网站加载速度
- Loading 与 Skeleton 体验
- 公开页、阅读页、AI 工作台和关键表单交互优化

## 2. 不做

- 全站重设计
- 更换 UI 框架
- Next.js 迁移
- Flutter
- 可视化页面搭建器
- 多租户主题市场

## 3. 阶段 A：主题剩余 UI

### 3.1 后台主题表单

后台主题表单补齐：

- 站点 Logo 上传 / 选择
- favicon 上传 / 选择
- SEO 标题
- SEO 描述
- SEO 关键词
- 公开区导航位置：顶部 / 左侧 / 右侧
- 功能开关
- 预览区

### 3.2 前台应用配置

公开前台需要按配置渲染：

- 顶部导航
- 左侧导航
- 右侧导航
- 移动端导航 Drawer
- Logo 和站点名称
- favicon
- SEO 信息

主题 token 需要尽量从系统配置读取并刷新前台。

### 3.3 验收

- 后台修改 Logo 后，公开前台可见。
- 后台修改导航位置后，公开前台布局正确。
- 移动端不出现导航挤压。
- SEO 字段可以写入页面 head 或由运行时读取。
- 配置失败时展示清晰错误。

## 4. 阶段 B：加载速度与 Loading 优化

加载速度优先级高于普通视觉微调。目标是让面试官打开网站时首屏更快、更稳定。

### 4.1 性能检查

先建立当前基线：

- 首页首屏加载时间
- 内容中心加载时间
- 小册阅读页加载时间
- AI 工作台加载时间
- 主 bundle 和路由 chunk 体积
- 图片、字体、图标加载情况

### 4.2 首屏优化

优先处理：

- 首页首屏资源体积
- 不必要的同步依赖
- 图片尺寸与懒加载
- 字体加载策略
- 图标和大型组件按需加载
- 路由级分包

不为了小幅指标牺牲代码可维护性。

### 4.3 Loading 页面

优化：

- 应用初始 Loading
- 路由切换 Loading
- 内容列表 Skeleton
- 小册阅读 Skeleton
- AI 生成中的等待态
- 后台表格和表单加载态

加载态要遵循实际内容结构，避免闪烁和布局跳动。

### 4.4 验收

- 首页、内容中心、小册阅读、AI 工作台有可接受的加载态。
- 慢网速下页面不出现大片空白。
- 控制台无本次新增错误。
- 性能优化前后有可对比记录。
- 加载态不遮挡固定导航、底部操作栏和表单按钮。

## 5. 阶段 C：页面 UI 与交互优化

### 5.1 优先页面

第一优先级：

- 首页
- 内容中心
- 小册阅读
- AI 工作台

第二优先级：

- 登录 / 注册 / 改密
- 工作区 Dashboard
- 后台首页

### 5.2 首页

优化方向：

- 更清楚表达「个人知识平台 + AI 工具中台」
- 强化内容、AI、项目能力入口
- 首屏行动按钮更明确
- 移动端排版稳定

### 5.3 内容中心

优化方向：

- 筛选区在手机端更易用
- 卡片信息层级更清楚
- 空状态和错误态更友好
- 分页和加载状态不跳动

### 5.4 小册阅读

优化方向：

- 章节切换更顺手
- 阅读进度更明显
- 大纲和章节入口在移动端更稳定
- 图片、代码块和表格不撑破视口

### 5.5 AI 工作台

优化方向：

- 模型选择更清楚
- 额度信息更易理解
- 生成中、失败、停止、重试状态更稳定
- 移动端输入区不挤压按钮

### 5.6 登录与表单

优化方向：

- 错误提示更明确
- 验证码、邮箱验证、忘记密码流程更顺
- 表单提交状态不重复触发

- SEO 配置读取接口

## 7. 风险与控制

- UI 优化容易发散：按页面优先级推进，先处理第一优先级。
- 样式覆盖风险：优先使用语义 class，不依赖 Ant Design 内部 DOM。
- 性能优化误伤功能：每次优化后跑核心流程。
- 移动端布局风险：必须验收 390px 和桌面宽度。
