> 适用范围：`/ai`、`/ai/chat`、`/ai/text`、`/ai/image`、`/workspace/ai/history`、`/workspace/usage`

---

## 1. 模块目标

AI 工具平台是项目主线能力，负责把内容库、模型厂商、用户配额和工具交互串起来。

首版目标：

- 工具广场展示 Chat、文本生成、图片生成入口。
- Chat 支持多会话、流式输出、历史保存、重新生成、复制。
- 文本生成支持多场景模板、流式输出、复制和重新生成。
- 图片生成支持基础参数、结果展示和下载。
- 登录用户消耗统一 Token 配额。
- 未登录用户仅可试用 Chat / 文本生成，且不保存历史。
- 后台可配置模型和厂商，用户端只展示可见模型。

暂不做：

- 视频生成。
- 支付充值。
- AI 结果一键发布到内容库。
- 复杂 Prompt 市场。
- 多人共享会话。

## 5. Chat 对话

### 5.1 页面结构

```txt
┌──────────────┬─────────────────────────────────────┐
│ 会话侧栏      │ 顶部：模型选择 / System Prompt       │
│ 新对话        ├─────────────────────────────────────┤
│ 会话列表      │ 消息列表                             │
│ 搜索          ├─────────────────────────────────────┤
│              │ 引用内容 / 输入框 / 发送 / 停止       │
└──────────────┴─────────────────────────────────────┘
```

移动端：

- 会话侧栏收起为抽屉。
- 输入区固定底部。
- 模型和高级设置放入顶部菜单。

### 5.2 会话字段

| 字段 | 说明 |
|---|---|
| `id` | 会话 ID |
| `title` | 会话标题，默认第一条消息前 20 字 |
| `modelId` | 使用模型 |
| `systemPrompt` | 系统提示词 |
| `messageCount` | 消息数 |
| `totalTokens` | 累计消耗 |
| `lastMessageAt` | 最后消息时间 |

### 5.3 消息字段

| 字段 | 说明 |
|---|---|
| `id` | 消息 ID |
| `role` | user / assistant / system |
| `content` | 消息内容 |
| `status` | streaming / done / error |
| `tokenCount` | token 数 |
| `feedback` | thumbs_down / null |
| `createdAt` | 创建时间 |

### 5.4 功能逻辑

- 新对话：创建空会话，第一条消息后自动命名。
- 发送消息：追加用户消息，发起 SSE，流式追加助手消息。
- 停止生成：中断当前请求，消息状态标为 `error` 或 `stopped`。
- 重新生成：仅对最后一条 AI 回复可用。
- 删除会话：二次确认。
- 引用内容：从内容库选择一篇内容，作为上下文注入请求，不直接展示全文。
- System Prompt：高级设置面板编辑，随会话保存。

### 5.5 SSE 事件

| type | 说明 |
|---|---|
| `delta` | 增量文本 |
| `done` | 完成，带 tokenUsage |
| `error` | 错误 |
| `quota_exceeded` | 配额不足 |

## 6. 文本生成

### 6.1 场景

| 场景 | 输入 | 参数 |
|---|---|---|
| 写作辅助 | 主题或草稿 | 输出长度、语气 |
| 改写润色 | 原文 | 语气 |
| 摘要提炼 | 原文 | 摘要条数、输出长度 |
| 扩写 | 原文 | 输出长度、语气 |
| 翻译 | 原文 | 目标语言 |
| 续写 | 原文 | 输出长度 |
| 自定义 Prompt | 指令 + 原文 | 模型 |

### 6.2 页面结构

```txt
┌─────────────────────┬──────────────────────────────┐
│ 场景 Tabs            │ 参数面板                       │
├─────────────────────┴──────────────────────────────┤
│ 输入区                                               │
├──────────────────────────────────────────────────────┤
│ [生成] [停止]                                        │
├──────────────────────────────────────────────────────┤
│ 输出区：流式结果 / 复制 / 重新生成                    │
└──────────────────────────────────────────────────────┘
```

### 6.3 校验

- 输入不能为空。
- 未登录输入最多 2000 字。
- 登录用户输入最多 8000 字，后续可根据模型上下文调整。
- 翻译模式必须选择目标语言。

## 7. 图片生成

字段：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `prompt` | string | 空 | 必填，最多 1000 字 |
| `negativePrompt` | string | 空 | 反向提示词 |
| `size` | enum | 1024x1024 | 1:1 / 16:9 / 9:16 |
| `count` | number | 1 | 1 / 2 / 4 |
| `style` | enum | realistic | 写实 / 动漫 / 油画 / 自定义 |
| `modelId` | string | 默认模型 | 图片模型 |

规则：

- 必须登录。
- 生成前检查 Token 余额。
- 生成成功展示图片网格。
- 支持下载。
- 保存到内容库后续实现。

## 8. Token 与用量

消耗记录：

- Chat：按输入输出 tokens 折算。
- 文本：按输入输出 tokens 折算。
- 图片：按次数折算，首版默认 1 张 500 Token。

扣减规则：

- 生成前预检查余额。
- 生成完成后按实际消耗扣减。
- SSE 中断时按已产生 token 记录。
- 扣减写入 `ai_usage_logs` 和 `token_transactions`。

用量页：

- 配额汇总。
- 近 30 天趋势。
- 工具消耗分布。
- 使用明细。

## 10. 状态与异常

| 场景 | 行为 |
|---|---|
| 模型不可用 | 禁用发送按钮并提示 |
| Token 不足 | 展示配额不足提示 |
| SSE 中断 | 保留已生成内容，允许重新生成 |
| 访客超限 | 弹登录引导 |
| 厂商 API 错误 | 展示错误，不扣除未产生的配额 |
| 删除会话 | 二次确认 |

---

## 11. 验收标准

- 工具广场能展示启用/禁用状态。
- Chat 能新建会话、发送消息、流式显示、保存历史。
- 文本生成能按场景生成并复制结果。
- 图片生成能提交参数并展示结果。
- Token 消耗能记录并反映到用量页。
- 配额不足时不能继续生成。
- 后台禁用模型后用户端不可选择。
